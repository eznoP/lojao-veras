## 💡 Sobre o projeto
O projeto iniciou quando surgiu o interesse por minha parte de aprender e trabalhar com a IA, e acho que a melhor forma que encontrei de aprender foi cirar este projeto.

O **Lojão Veras** é uma loja de iluminação que meus avós construiram há mais de 20 anos, afim de ser seu "hooby" após suas aposentadorias.
Analisando sua parte tecnológica, é visto que não existem sites nem nada muito complexo para representar a loja, por isso decidi criar um site para que as pessoas "visitem" a loja mesmo sem ir até ela, além disso, aprendi e estou aprendendo coisas que são importantes para meu sonho, que é ser um programador que ajuda e resolve problemas da sociedade.
